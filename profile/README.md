# Seagit

Tools for shipping software: a Kubernetes DevOps platform, a form builder that sends every response where your team already works, and a set of free browser-based developer tools.

## Products

### [SeaGit](https://seagit.com) — Kubernetes DevOps platform

Deploy Kubernetes to your own AWS account in minutes, with GitOps CI/CD and ephemeral environments.

- **Your cloud, your account.** Clusters run in your AWS account, not ours. Azure and GCP are on the roadmap.
- **Preview environments.** Every push can get its own isolated deployment with its own URL, without touching the main deployment.
- **CI/CD built in.** GitHub pushes build and deploy automatically.
- **Free plan.** [See pricing](https://seagit.com/pricing).

### [Seagit Forms](https://forms.seagit.com) — online form builder

Build a form, share one link, and send each response to a system instead of an inbox.

- **Destinations:** [webhooks](https://forms.seagit.com/docs/webhooks) and [Telegram](https://forms.seagit.com/docs/telegram) on every plan. [Slack](https://forms.seagit.com/docs/slack), [Discord](https://forms.seagit.com/docs/discord), [Microsoft Teams](https://forms.seagit.com/docs/teams), [Google Chat](https://forms.seagit.com/docs/google-chat), [Google Sheets](https://forms.seagit.com/docs/google-sheets), [Airtable](https://forms.seagit.com/docs/airtable), [Notion](https://forms.seagit.com/docs/notion) and email on paid plans. [All integrations](https://forms.seagit.com/integrations).
- **266 ready-made [form templates](https://forms.seagit.com/templates)**, from contact and RSVP forms to job applications.
- **Free:** 10 forms with 100 responses each, no card required. [Plans](https://forms.seagit.com/plans).

### [Seagit Tools](https://tools.seagit.com) — free developer tools

More than 240 tools that run entirely in your browser. Nothing is uploaded and there's no signup.

- Format and validate JSON, YAML and XML
- Convert between data formats and generate code types
- Run code in 15+ languages
- Base64 encoding, time zone conversion and more
